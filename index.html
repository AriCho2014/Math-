Quadratics:

For the form ax² + bx + c = 0, x =

- b ± b 2 - 4 a c 2 a

Reason:

The quadratic formula works by using a technique called "completing the square" to isolate the variable x in any standard quadratic equation. Instead of completing the square from scratch every time, the formula acts as a shortcut that gives you the answer immediately.

1. Start with the standard form: Every quadratic equation can be written with all terms on one side, where a≠0.

a x 2 + b x + c = 0

2. Divide by the leading coefficient: Divide every term by a so that the coefficient in front of x2 becomes 1.

x2 + bax + ca = 0

3. Move the constant term: Subtract ca from both sides to get the x terms by themselves.

x2 + bax = -ca

4. Complete the square: Take half of the coefficient of x (which is b2a), square it to get b24a2, and add it to both sides. This turns the left side into a perfect square trinomial.

x2 + bax + b24a2 = b24a2 - ca

5. Factor and combine fractions: Rewrite the left side as a squared binomial. On the right side, give both fractions a common denominator of 4a2 so you can combine them.

( x+b2a ) 2 = b2-4ac 4a2

6. Take the square root of both sides: Taking the square root cancels out the exponent on the left. Remember to include the ± symbol on the right because both positive and negative roots are valid.

x+b2a = ±b2-4ac 2a

7. Isolate x: Subtract b2a from both sides. Because the fractions share the same denominator, you can merge them into the final quadratic formula.

x = -b±b2-4ac 2a

Reason:

This works because of the distributive property.

1. Rewriting the form.

0 - b 1 a , 0 - b 2 a

to

( x + b 1 a ) ( x + b 2 a ) = 0

2. Using the distributive property.

( x + b 1 a ) ( x + b 2 a ) = ( x · x ) + ( x · b 2 a ) + ( b 1 a · x ) + ( b 1 a · b 2 a )

3. Simplifying.

( x · x ) + ( x · b 2 a ) + ( b 1 a · x ) + ( b 1 a · b 2 a ) = ( x 2 ) + ( b 1 + b 2 a x ) + ( b 1 · b 2 a 2 )

4. From before we know that [ b 1 + b 2 = b , b 1 · b 2 = a c ] so we can simplify further.

( x 2 ) + ( b 1 + b 2 a x ) + ( b 1 · b 2 a 2 ) = x 2 + b a x + a c a 2

5. The a's cancel out leaving this.

x 2 + b a x + a c a 2 = x 2 + b a x + c a

6. We can finally multiply a with evrything to get our standard form.

x 2 + b a x + c a = a x 2 + b x + c = 0

Logarithims:

Product Rule:

log b ( m · n ) = log b ( m ) + log b ( n )

Quotient Rule:

log b ( m n ) = log b ( m ) - log b ( n )

Change of Base Rule:

log b ( m ) = log c ( m ) log c ( b )

Power Rule:

log b ( m n ) = n · log b ( m )
